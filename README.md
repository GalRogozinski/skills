# skills

Agent skills in the `SKILL.md` format. Works with Claude Code, and can be added to
[Rakazo](https://github.com/elie222/rakazo) from **Skills → From GitHub**.

| Skill | What it does |
|---|---|
| `eli-x` | Ends tasks with a plain-language wrap-up and gives hard multi-step work memorable stage names. |
| `rfc` | Drafts and reviews RFCs / design specs so independent implementations stay compatible. Mirrors a repo's existing RFC conventions. |
| `pr-review` | Reviews a pull request: read the thread first, one comment format, verify every claim, ask before posting. |
